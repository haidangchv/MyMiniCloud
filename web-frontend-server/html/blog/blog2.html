Nginx phục vụ Web và làm reverse proxy

Tác giả: xbanghjhj

Phục vụ nội dung tĩnh

Nginx có thể đọc file HTML, CSS và ảnh từ hệ thống file để trả về cho trình duyệt. Trong MyMiniCloud, nội dung Web được đặt tại /usr/share/nginx/html.

Vai trò reverse proxy

Khi làm reverse proxy, Nginx nhận request, chuyển đến server phía sau, rồi trả phản hồi về client. Cấu hình location và proxy_pass xác định cách định tuyến request.

Phân biệt hai vai trò trong dự án

  • Web Server: phục vụ các trang HTML và tài nguyên tĩnh.
  • API Gateway: chuyển request đến Web hoặc backend phù hợp.

Ở mốc Web cơ bản, trình duyệt truy cập cổng 8080 của Windows; Docker chuyển kết nối đến cổng 80 trong container Web.
