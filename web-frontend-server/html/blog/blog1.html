Dockerfile, image và container khác nhau thế nào?

Tác giả: xbanghjhj

Ba thành phần cần phân biệt

  • Dockerfile: mô tả các bước xây dựng image.
  • Image: khuôn mẫu chỉ đọc để tạo container.
  • Container: một instance được tạo từ image.

Áp dụng trong MyMiniCloud

Dockerfile sao chép cấu hình Nginx và các file HTML vào image myminicloud-web:dev. Service web-frontend-server dùng image đó để phục vụ website.

Khi sửa HTML, ta build lại image và cập nhật container.

docker compose up -d --build web-frontend-server
